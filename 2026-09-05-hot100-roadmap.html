LeetCode Hot100 突击计划：我准备这样刷算法

2026-09-05

最近准备重新系统刷一遍 LeetCode Hot100。

以前刷题最大的一个问题就是"想到哪刷到哪"，做了几十题以后发现很多知识点其实是重复的，有些题隔几个月又不会了。而且面试的时候，面试官问的从来不是"你刷过多少题"，而是"你遇到这个问题知不知道该用什么方法"。

这次准备换一种方式：

不是按题号刷，而是按专题刷。

每个专题只学一种核心思想，把经典题全部吃透。我希望最后形成的不是"我做过 100 题"，而是：

  • 我看到数组题，知道什么时候该用双指针
  • 看到子串问题，知道什么时候该滑窗口
  • 看到最值问题，知道该贪心还是 DP
  • 看到搜索问题，知道该 DFS 还是 BFS
  • 看到排列组合，知道回溯的模板长什么样

    • 整个计划大概分成 15 个专题，每完成一个专题就写一篇博客总结，顺便整理模板代码。以后需要复习的时候，看博客比重新刷题快得多。

    下面是我给自己规划的完整路线图。

    ---

    ① 双指针与数组 ★★★★★

    公司最爱，几乎必考。

    双指针是所有数组题的基础思想。核心就三种用法：

  • 相向指针：左右往中间夹，典型如盛水容器、接雨水
  • 快慢指针：一个快一个慢，典型如移动零、删除重复元素、链表环检测
  • 滑动窗口：双指针的进阶版，窗口大小动态变化

    • 推荐刷题清单：

    
两数之和
三数之和
盛最多水的容器
接雨水
移动零
颜色分类
删除有序数组中的重复项

    一句话总结：看到"原地修改数组""去重""配对"这类关键词，先想双指针。

    ---

    ② 滑动窗口 ★★★★★

    几乎所有互联网公司都会问，尤其字节、腾讯、美团。

    滑动窗口是双指针的升级版，但思考方式完全不同。核心要搞清楚三件事：

  • 什么时候扩窗口：右指针什么时候往右走
  • 什么时候缩窗口：左指针什么时候往右走
  • 什么时候更新答案：是在扩的时候更新还是缩的时候更新

    • 推荐刷题清单：

    
无重复字符的最长子串
找到字符串中所有字母异位词
最小覆盖子串
长度最小的子数组
水果成篮

    一句话总结：看到"连续子数组/子串 + 最值"的组合，十有八九是滑动窗口。

    ---

    ③ 哈希表 ★★★★★

    最基础的数据结构，但用好了能秒杀很多题。

    哈希的核心价值就两个：一是 O(1) 查找，二是用空间换时间。

    常见用法：

  • HashMap 存下标：两数之和
  • HashMap 存计数：字母异位词分组
  • HashSet 去重：最长连续序列
  • LinkedHashMap 维护顺序：LRU 缓存

    • 推荐刷题清单：

    
两数之和
字母异位词分组
最长连续序列
LRU 缓存

    一句话总结：暴力解法超时的时候，想想能不能用哈希把 O(n²) 变成 O(n)。

    ---

    ④ 二分查找 ★★★★★

    模板简单，但边界条件最容易写错。

    二分的核心不是"有序数组"，而是"答案具有单调性"。只要能找到一个条件把搜索空间一分为二，就能用二分。

    必须记住的模板细节：

  • while (left < right) 还是 left <= right？
  • mid 要不要 +1 或 -1？
  • 最后返回 left 还是 right？

    • 推荐刷题清单：

    
搜索旋转排序数组
寻找峰值
寻找重复数
两个有序数组的中位数

    一句话总结：看到"有序"或"部分有序"别急着遍历，先想能不能二分。

    ---

    ⑤ 链表 ★★★★★

    面试最喜欢手撕的题型，因为能同时考察指针操作和边界处理。

    链表题的核心套路就一套：

  • dummy 节点：处理头节点可能被删除的情况
  • pre / cur / next：三个指针配合完成反转、删除、插入
  • 快慢指针：找中点、判环

    • 推荐刷题清单：

    
反转链表
K 个一组翻转链表
环形链表
排序链表
相交链表
删除链表的倒数第 N 个节点

    一句话总结：链表题不怕难，画个图把指针指向标清楚，基本就做对了一半。

    ---

    ⑥ 二叉树 DFS ★★★★★

    递归是核心，模板化最强。

    二叉树 DFS 的三种遍历方式（前序、中序、后序）是所有树题的基础。关键要理解：

  • 什么时候用前序：需要在进入子树前做处理（比如构造树）
  • 什么时候用中序：BST 相关、找第 K 小
  • 什么时候用后序：需要从子树返回信息给父节点（比如最大深度、直径）

    • 推荐刷题清单：

    
二叉树的最大深度
二叉树的最大直径
路径总和系列
最近公共祖先
验证二叉搜索树

    一句话总结：树的问题先想递归，想清楚"当前节点需要子节点返回什么信息"，模板就出来了。

    ---

    ⑦ BFS ★★★★★

    层序遍历 + 最短路径。

    BFS 的核心工具就一个队列，关键要搞清楚：

  • 什么时候标记 visited：入队时还是出队时？
  • 怎么记录层数：用 for 循环包一层，或者用 pair<node, depth>
  • 什么时候 BFS 比 DFS 好：求最短路径、层序相关

    • 推荐刷题清单：

    
二叉树的层序遍历
岛屿数量
腐烂的橘子
打开转盘锁

    一句话总结：看到"最短""最少步数""层序"，先想 BFS。

    ---

    ⑧ 回溯 ★★★★★

    互联网大厂特别喜欢，因为能考递归思维。

    回溯的本质是穷举，但穷举也有模板：

    
path    → 当前路径
choices → 可选列表
end     → 结束条件
undo    → 撤销选择

    推荐刷题清单：

    
全排列
子集
组合总和
N 皇后
括号生成

    一句话总结：看到"所有组合""所有可能"，先想回溯。剪枝是加分项，但先保证能跑通再优化。

    ---

    ⑨ 动态规划 ★★★★★（最大专题）

    整个 Hot100 里题量最大、区分度最高。

    DP 建议拆成四个子专题来学，不要混在一起：

    线性 DP

    
爬楼梯
打家劫舍
最大子数组和
最长递增子序列

    背包 DP

    
零钱兑换
完全平方数
目标和

    区间 DP

    
最长回文子串
编辑距离

    股票 DP

    
买卖股票的最佳时机 I ~ IV

    一句话总结：DP 的思考顺序永远是——先定义状态，再找转移方程，最后想初始化和遍历顺序。不要一上来就写代码。

    ---

    ⑩ 贪心 ★★★★★

    代码短，但证明难。

    贪心的核心问题是：为什么局部最优能推出全局最优？面试时如果能把这个讲清楚，比写出代码更重要。

    推荐刷题清单：

    
跳跃游戏 I / II
分发糖果
划分字母区间
买卖股票的最佳时机 II

    一句话总结：贪心适合"每一步做当前看起来最好的选择"，如果证明不了，就用 DP 兜底。

    ---

    ⑪ 图论 ★★★★★

    近几年越来越热门，尤其字节、拼多多、米哈游。

    图的核心算法就四个：

  • DFS / BFS：遍历
  • 并查集（Union Find）：连通性判断
  • 拓扑排序（Topo）：依赖关系、课程表

    • 推荐刷题清单：

    
课程表 I / II
冗余连接
岛屿数量（并查集版）
最小生成树（Kruskal）

    一句话总结：图论题看起来吓人，但大部分面试只考模板——把并查集和拓扑排序的模板背熟，覆盖 80%。

    ---

    ⑫ 堆 / 优先队列 ★★★★☆

    处理"前 K 个""第 K 个"类问题。

    推荐刷题清单：

    
前 K 个高频元素
合并 K 个有序链表
数据流的中位数

    一句话总结：看到"前 K""最大/最小 K 个"，先想堆。

    ---

    ⑬ 单调栈 ★★★★★

    几乎每年都有，尤其字节、腾讯。

    单调栈的核心思想：维护一个单调递增或递减的栈，让每个元素只进出一次，把 O(n²) 变成 O(n)。

    关键要搞清楚：

  • 什么时候维护递增栈：找下一个更小
  • 什么时候维护递减栈：找下一个更大

    • 推荐刷题清单：

    
每日温度
柱状图中最大的矩形
接雨水
下一个更大元素

    一句话总结：看到"下一个更大/更小""左右第一个比它大/小"，单调栈基本是标准答案。

    ---

    ⑭ 前缀和 ★★★★★

    把 O(n²) 变成 O(n) 的利器。

    推荐刷题清单：

    
和为 K 的子数组
二维区域和检索
航班预订统计（差分）

    一句话总结：看到"区间和查询"频繁出现，先想前缀和；看到"区间批量加减"，想差分。

    ---

    ⑮ 位运算 ★★★★☆

    题量少但性价比高，容易出冷门题。

    推荐刷题清单：

    
只出现一次的数字系列
多数元素
汉明距离

    一句话总结：看到"只出现一次""不用额外空间"，想想位运算能不能搞定。

    ---

    最后：模板汇总

    整个系列刷完，我准备把所有模板整理成一张速查表，大概长这样：

    
双指针        → 相向 / 快慢 / 滑动窗口
二分查找      → 左闭右开 / 左闭右闭
DFS           → 前中后序递归模板
BFS           → Queue + visited + 层数
回溯          → path / choices / end / undo
DP            → 状态定义 → 转移方程 → 初始化 → 遍历顺序
贪心          → 局部最优 → 证明全局最优
并查集        → find / union / 路径压缩
拓扑排序      → 入度表 + BFS
单调栈        → 递增找小 / 递减找大
前缀和        → pre[i] = pre[i-1] + nums[i]
堆            → PriorityQueue 大小顶堆

    ---
