你好,世界

2026-09-04

这是我的第一篇博客文章。

这个站点是用一个很简单的 Python 脚本生成的:每篇文章是一个 Markdown 文件,放在 posts/ 目录下,运行 python3 build.py 就会把它们渲染成静态 HTML 页面,输出到 site/ 目录。

之所以这样做,是因为它足够透明——没有黑盒框架,没有几百个依赖包,想改样式就直接改 style.css,想改排版逻辑就直接改 build.py。等以后需要更多功能(比如分页、评论、搜索),可以再逐步加。

代码块也是支持的


def greet(name: str) -> str:
    return f"你好, {name}!"

print(greet("世界"))
