为什么我选择自己写静态站点生成器

2026-09-03

市面上的静态博客框架(Hexo、Jekyll、Hugo)功能都很全,但对于一个刚起步、只想写点东西的博客来说,有时候反而是负担:要装 Node/Ruby/Go 环境,要学一套主题系统,升级时还可能踩依赖版本的坑。

这个博客用的是一个不到 150 行的 Python 脚本:

1. 读取 posts/*.md,解析文件头(标题、日期、标签)

2. 用 markdown 库把正文转成 HTML

3. 套进一个简单的 HTML 模板

4. 输出到 site/ 目录,直接就是可以部署的静态文件

好处是每一行代码我都看得懂,想加什么功能就自己加。坏处是主题、插件生态肯定不如成熟框架。等博客写多了、需求变复杂了,再迁移到 Hexo 或 Hugo 也不迟——Markdown 文件本身是通用的,迁移成本不高。
